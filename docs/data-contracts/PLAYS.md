# Plays Contract

Grain: one source play/event. Stable identity is source play ID within `game_id`; canonical state also carries season/type/week, drive ID, offense, defense, period/clock, down, distance, yards-to-goal, normalized event type/subtype, text evidence, analytics yards, scrimmage/offensive flags, transition/no-play flags, validation status, and definition versions. Source omissions are nullable; fields used by a metric must pass that metric's eligibility rule.

# CFB Analytics

A reliability-first college football data project.

## Phase 1: raw historical data foundation

The only current goal is to acquire and preserve raw college football **game**, **drive**, and **play-by-play** data week by week for the seasons 2014–2025, excluding 2020.

This phase does **not** clean, reinterpret, classify, aggregate, score, or model football data. Raw source records are evidence and must remain reproducible.

Target seasons: `2014, 2015, 2016, 2017, 2018, 2019, 2021, 2022, 2023, 2024, 2025`.

Read `docs/architecture.md`, `docs/raw-data-contract.md`, and `docs/acquisition-plan.md` before implementing ingestion.
